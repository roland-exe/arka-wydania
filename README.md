# A.R.K.A. – wydania

Publiczne repozytorium informacji o wersjach programu **A.R.K.A. – Asystent Rozliczeń i Księgowości Administracji** (Hillerset, autor: Roland Hiller).

- `latest.json` – informacja o najnowszej wersji i dostępnych pakietach aktualizacji; program A.R.K.A. sprawdza ten plik (można to wyłączyć w menu „Aktualizacja”).
- `*.arka` – pakiety aktualizacji danych, podpisane cyfrowo przez autora; program instaluje je dopiero po weryfikacji podpisu.

Repozytorium nie zawiera kodu źródłowego ani kluczy. Program jest utworem chronionym prawem autorskim; zasady korzystania opisuje licencja dostępna w programie (menu „Warunki licencji”).
